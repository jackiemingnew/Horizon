## [ChainDrop Worm Breaches 1,300+ npm Packages, Steals Credentials](https://www.bleepingcomputer.com/news/security/massive-chaindrop-npm-supply-chain-attack-infects-hundreds-of-packages/) ⭐️ 9.0/10

ChainDrop, a self-propagating worm, has compromised more than 1,300 npm packages, including Keyv and Cacheable, with a combined 2 billion monthly downloads. The attack began when the Keyv maintainer's GitHub account was compromised, allowing malicious versions to be published through legitimate GitHub Actions workflows. This is a high-impact supply chain attack because it targets widely used open-source caching libraries and can steal credentials from developer and CI/CD environments. Anyone who installed affected versions should treat their systems as compromised, rotate all tokens, and rebuild their environments. The malicious packages execute a setup.mjs dropper and Math_Symbol.js info-stealer automatically during npm install, harvesting GitHub, npm, AWS, and Kubernetes credentials. StepSecurity reported at least 444 packages and 2,212 poisoned versions as of its analysis, and npm-cache[.]com is a known indicator of compromise.

telegram · zaihuapd · Aug 5, 03:04

**Background**: npm is the default package manager for Node.js, and supply chain attacks occur when malicious code is injected into legitimate open-source packages that developers then install as dependencies. ChainDrop is reportedly a variant of the Shai-Hulud worm and spreads by infecting other maintainers' packages once it steals credentials. Keyv is a simple key-value storage library widely used in the Node.js ecosystem, and the compromise of its maintainer's account allowed the attacker to publish updates via trusted GitHub Actions CI/CD pipelines.

## [ByteDance Launches SeedRealtime, Native Full-Duplex Audio-Video Model in Doubao](https://seed.bytedance.com/zh/blog/seedrealtime-%E9%9F%B3%E8%A7%86%E9%A2%91%E5%85%A8%E5%8F%8C%E5%B7%A5%E5%A4%A7%E6%A8%A1%E5%9E%8B%E5%8F%91%E5%B8%83-%E8%B5%B0%E5%90%91%E5%85%A8%E6%A8%A1%E6%80%81%E8%87%AA%E7%84%B6%E4%BA%A4%E4%BA%92) ⭐️ 9.0/10

On August 5, ByteDance released SeedRealtime, a native full-duplex audio-video large model now fully available in the Doubao app. It unifies audio, video, and text in a single end-to-end architecture, enabling real-time interaction over continuous multimodal streams. SeedRealtime marks a shift from cascaded ASR-VLM-TTS pipelines to a unified end-to-end multimodal model, reducing latency and information loss. This could accelerate the adoption of natural, human-like real-time voice and video interaction across consumer AI products. The model integrates perception, understanding, decision-making, and expression into one model, and does not require an external VAD module to determine turn-taking. End-to-end human evaluation shows the model halves audio-video conversation pacing problems compared with cascaded models, significantly reducing interruptions such as users being cut off mid-speech.

telegram · zaihuapd · Aug 5, 04:42

**Background**: Traditional voice AI systems are 'half-duplex': they take turns listening and speaking, often relying on separate ASR, VLM, and TTS modules linked together (a cascade), which adds latency and loses information at each step. Full-duplex dialogue, by contrast, allows simultaneous listening and speaking, with dynamic turn-taking, overlapping speech, and backchanneling, similar to human conversation. SeedRealtime is an end-to-end model that directly learns such behavior from multimodal streams rather than composing independent modules.

## [LLM 0.32 adds reasoning traces, server-side tools, and smarter logging](https://simonwillison.net/2026/Aug/4/new-release-of-llm/#atom-everything) ⭐️ 8.0/10

LLM 0.32, the most significant update since the project's launch, now displays reasoning traces from reasoning models to standard error, supports server-side tools such as OpenAI's CodeInterpreter and WebSearch, and introduces redesigned content-addressable SQLite logs. It also adds out-of-the-box support for the GPT-5.6 model family, with GPT-5.6 Luna as the new default model for `llm` prompts. For developers who use LLM as a command-line tool for interacting with language models, these features make reasoning processes visible, enable server-side tool use without client-side setup, and improve logging for auditability. The move to default GPT-5.6 Luna also makes the tool more cost-effective while retaining capability. Reasoning traces are written to standard error so they do not pollute piped output; use `-R/--hide-reasoning` to suppress them. The new `llm openai endpoint` command lets users run one-off prompts against any OpenAI-compatible endpoint without configuration, and those prompts are not logged.

rss · Simon Willison · Aug 4, 23:58

**Background**: The OpenAI Responses API is a developer interface introduced by OpenAI to simplify building agentic applications, combining the ease of the Chat Completions API with advanced tool-calling capabilities. LLM is a command-line tool for interacting with large language models from various providers via plugins. Reasoning models are LLMs trained to solve complex tasks via multi-step logical reasoning, often generating internal reasoning traces. Content-addressable storage organizes data by content rather than location, enabling deduplication and integrity checks.

## [FFmpeg 9.0 Released with Animated WebP Support and Claude-Assisted Development](https://news.ycombinator.com/item?id=49166202) ⭐️ 8.0/10

FFmpeg 9.0 is officially released, adding an animated WebP decoder and demuxer, a v360_vulkan filter, a Playdate video encoder and muxer, HE-AAC 960 decoding (DAB+), a transpose_cuda filter, an AMF framerate conversion filter, and an ONNX Runtime DNN backend. The development team also received six months of free Claude Max through Anthropic's Claude for Open Source Program, using AI mainly to find missing backports. This is a major release of the most widely used multimedia framework, bringing practical improvements for WebP animation, 360-degree video processing, and Playdate game development. It also highlights the growing role of AI-assisted development in mature open-source projects, while raising questions about review and safety processes. The v360_vulkan filter is a Vulkan-compute-based 360-degree video converter supporting formats like equirectangular projection and cubemap layouts. The ONNX Runtime backend, contributed by AMD engineer Steven Xiao, expands GPU and NPU capabilities for FFmpeg's DNN filter. Animated WebP support means FFmpeg can now decode and demux animated WebP files.

telegram · zaihuapd · Aug 5, 10:32

**Background**: FFmpeg is a free, open-source suite of libraries and tools for handling video, audio, and other multimedia files and streams. It is widely used by media players, transcoders, and streaming platforms. Major version releases like 9.0 bundle many new filters, encoders, decoders, and backends contributed by various developers and companies. The Claude for Open Source Program provides free access to Anthropic's AI assistant for maintainers of open-source projects.
