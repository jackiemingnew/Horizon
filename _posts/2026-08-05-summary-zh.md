## [Discovery Loop：自动化科学工程实验循环的机构级尝试](https://www.discoveryloop.com/) ⭐️ 9.0/10

Discovery Loop 是一家由 Jeff Dean 等谷歌资深 AI 研究人员创立的新公司，宣布要以机构级规模自动化实验循环。公司将首先聚焦机器学习研究与工程，并目标将该方法推广至更广泛的科学与工程领域。 这可能通过从常规实验中移除人类瓶颈，大幅加速迭代式研发。这也表明资深 AI 人才离开大型科技公司、投身自主科学发现正成为一种趋势。 该公司将使命描述为“持续探索”（Continuous Exploration），希望让实验流程高度并行并自动化。Jeff Dean 的公开帖提到，这一方法不仅限于机器学习，还可能有助于应对美国国家工程院（NAE）绝大多数“大挑战”问题。

自我传播的 ChainDrop 蠕虫已攻陷超过 1300 个 npm 包，包括 Keyv 和 Cacheable，受影响包合计月下载量达 20 亿次。攻击始于 Keyv 维护者的 GitHub 账号被入侵，恶意版本通过合法的 GitHub Actions 工作流被发布。 这是一次高影响力的供应链攻击，因为它针对广泛使用的开源缓存库，并能从开发者和 CI/CD 环境中窃取凭证。任何安装过受影响版本的人都应将系统视为已失陷，轮换所有令牌并重建环境。 恶意包会在 npm install 过程中自动执行 setup.mjs 投放器与 Math_Symbol.js 窃密脚本，收集 GitHub、npm、AWS 和 Kubernetes 的凭证。StepSecurity 在分析中报告至少 444 个包、2212 个被投毒的版本，npm-cache[.]com 是已知的失陷指标。

## [字节跳动发布原生音视频全双工模型 SeedRealtime，豆包全量上线](https://seed.bytedance.com/zh/blog/seedrealtime-%E9%9F%B3%E8%A7%86%E9%A2%91%E5%85%A8%E5%8F%8C%E5%B7%A5%E5%A4%A7%E6%A8%A1%E5%9E%8B%E5%8F%91%E5%B8%83-%E8%B5%B0%E5%90%91%E5%85%A8%E6%A8%A1%E6%80%81%E8%87%AA%E7%84%B6%E4%BA%A4%E4%BA%92) ⭐️ 9.0/10

8 月 5 日，字节跳动发布了原生全双工音视频大模型 SeedRealtime，并已在豆包 App 全量上线。该模型采用统一架构融合音频、视频与文本，可在连续多模态信息流上进行实时交互。 SeedRealtime 标志着从 ASR-VLM-TTS 级联流水线向统一端到端多模态模型的转变，降低了延迟和信息损耗。这可能推动消费级 AI 产品更快采用自然、类人的实时语音与视频交互方式。 该模型将感知、理解、决策与表达整合进同一个模型，无需外置 VAD 模块判断轮次。端到端人工评测显示，相比级联模型，其音视频对话节奏问题减少一半，“话未说完被抢断”等卡壳现象显著减少。

telegram · zaihuapd · 8月5日 04:42

**背景**: 传统语音 AI 系统是“半双工”的：它们通过独立模块（如 ASR、VLM、TTS）级联实现轮流听和说，每一步都会增加延迟并造成信息损耗。全双工对话则允许同时听和说，支持动态轮转、重叠语音和反馈语，更接近人类对话。SeedRealtime 是一种端到端模型，直接从多模态信息流中学习这类行为，而不是拼接独立模块。

## [LLM 0.32 新增推理轨迹、服务端工具与更智能日志](https://simonwillison.net/2026/Aug/4/new-release-of-llm/#atom-everything) ⭐️ 8.0/10
