## [Go 1.27 发布：引入泛型方法、UUID 标准库与后量子密码学](https://go.dev/blog/go1.27) ⭐️ 9.0/10

Go 1.27 引入了泛型方法，允许在方法上使用类型参数，并支持在没有显式类型参数的情况下调用泛型函数。该版本还新增了标准库 UUID 包，并更新了基于 ML-DSA 的后量子密码学支持。 泛型方法消除了 Go 泛型设计中的长期限制，使泛型 API 更具表现力和可复用性。新增的标准库 UUID 包减少了对第三方库的依赖，而主动的后量子密码支持有助于整个生态为未来的安全威胁做好准备。 此版本中，泛型方法仅支持在泛型类型的方法上使用，相比其他语言中的完整泛型方法仍有许多限制。浮点数解析和格式化改用 Russ Cox 的 uscale 算法以提升性能；crypto/tls 增加了 ML-DSA（FIPS 204）混合支持。

hackernews · database64128 · 8月19日 18:33 · [社区讨论](https://news.ycombinator.com/item?id=49365405)

**背景**: Go 1.27 是 Go 编程语言的最新主要版本，该语言广泛用于云基础设施、微服务和命令行工具。泛型在 Go 1.18 中引入，而泛型方法一直是呼声很高的扩展。后量子密码学指设计用于抵御量子计算机攻击的算法，Go 加密团队一直在积极将其集成到标准库中。

**社区讨论**: 评论者对泛型方法和新的 UUID 包表示欢迎，同时提到了 uscale 浮点优化。有人对加密团队的后量子工作感到兴奋，也有人预测会出现一波从 google/uuid 迁移到新标准库的拉取请求。

**背景**: Git 标签通常用于标记代码的特定发布版本，方便开发者获取准确的源码快照。GPLv2 许可证要求分发者向接收者提供对应源码，如果获取方式被设计得极不合理，可能被视为违反许可证。安卓历史上一直使用 Git 标签来发布内核及其他 GPL 组件的源码。
