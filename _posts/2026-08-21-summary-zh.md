## [美国公民因在边境删除手机数据面临重罪指控](https://www.nytimes.com/2026/08/21/us/politics/samuel-tunick-deleted-phone-felony.html) ⭐️ 9.0/10

据《纽约时报》报道，美国公民塞缪尔·图尼克（Samuel Tunick）因在边境检查期间删除手机数据而面临重罪指控。事件发生在美国入境口岸，引发了关于数字隐私权的讨论。 该案考验了边境搜查权力与第四修正案在数字时代的界限。若被定罪，可能开创先例，将政府搜查期间删除个人数据的行为定为犯罪，影响无数旅客和数字权利。 据报道，这些指控为重罪，反映出政府认为删除数据构成妨碍司法或销毁证据。该事件凸显了边境官员的无证搜查权力，这比常规执法程序更为宽泛。

hackernews · floathub · 8月21日 12:10 · [社区讨论](https://news.ycombinator.com/item?id=49386895)

一位安全研究员意外发现，一个被忽视的 ENUM/e164.arpa 配置错误使得他们能够记录数十万条发往军事基地的电话元数据。这一发现暴露了电话基础设施安全中的严重漏洞。 这一发现意义重大，因为它表明像 ENUM 这样几乎被遗忘的协议仍然可能泄露敏感的通话元数据，可能危及军事和政府通信。这也凸显了加强对关键电话基础设施监管和安全的紧迫性。 问题源于 e164.arpa 域中一个配置错误的委派，该域用于通过 DNS 映射 E.164 电话号码。作者报告了该漏洞但未获得奖励，相关基础设施此后已得到处理。

hackernews · gavide · 8月21日 13:11 · [社区讨论](https://news.ycombinator.com/item?id=49387570)

**背景**: ENUM 是一种将电话号码转换为 e164.arpa 域下基于 DNS 的记录的协议，用于实现呼叫转移和 VoIP 路由等功能。e164.arpa 区域被委派给各国管理者，配置错误可能泄露敏感的通话元数据。这一事件表明，即使被认为'已死'的协议，如果配置不当，仍可能承载关键数据。

Anna's Archive 发布博文，呼吁紧急数字化稀有纸质书，警告 AI 公司正在购买并销毁这些书籍以获取训练数据。文章认为，独特实体拷贝的损毁是不可逆的文化与历史损失。 这件事凸显了 AI 对数据的巨大需求与文化遗产保护之间的冲突。如果这种操作持续下去，稀有或唯一的作品可能在扫描前就消失，影响研究者、历史学家和公众。 博文指出，无损扫描的成本可能高达 10 倍，因此一些 AI 公司选择裁切或销毁书籍以降低成本。文中还提到此前的大规模数字化项目（如 Google Books/Project Ocean），这些项目曾面临法律挑战，但并未销毁实体书。

## [研究发现：让 LLM“简洁”可省输出成本，压缩输入无效](https://www.reddit.com/r/MachineLearning/comments/1vulfei/does_telling_an_llm_to_be_concise_actually_save/) ⭐️ 8.0/10

一项跨模型研究在 9 个 LLM 上对比了“指令式输出压缩”与“输入提示缩短”。结果发现，输出压缩平均节省约 1.5 倍 API 成本（最高 3 倍）且准确率基本不变，而输入压缩会使成本最高增加 96%并降低准确率。 对于按 token 付费的开发者来说，这提供了一个简单可量化的优化手段：让模型写短答案，而不是自己删减提示词。该结果也验证了 Claude Code 等工具中“简洁输出风格”的价值，并提示供应商应更透明地为这类选项定价。 研究覆盖了 GPT-4o、GPT-5.4、Claude Haiku 4.5、Claude Sonnet 4.6、Qwen2.5-VL-7B、Qwen3.5-9B、DeepSeek-R1-Distill、Gemma-4-E4B 和 Kimi-K2.6，设有 5 个缩减等级、5 个短答案数据集和 11 种语言测试。一个注意点是：当压缩后的输出正确时，约有一半情况下它已不再与模型不受约束时的推理文本一致。

reddit · r/MachineLearning · /u/ibubbles34 · 8月21日 16:38

**背景**: LLM 的 API 定价一般按 token 计费，且输出 token 通常比输入 token 更贵，因此回复长度直接影响账单。提示工程常试图同时压缩输入和输出，但本研究将两个渠道分开验证：缩短提示词，与指示模型简要作答。Claude Code 最近上线了“简洁输出风格”(concise output style)选项，使得这一成本问题对开发者更具现实意义。

特斯拉正在中国发起其史上最大规模召回，通过 OTA 空中更新为超过 500 万辆汽车推送软件修复。自 9 月 25 日起，约 298 万辆进口和国产 Model 3、Model Y、Model S、Model X 将获得针对紧急车门释放把手问题的修复；同时，约 274 万辆国产 Model 3 和 Model Y 被立即召回，以增强驾驶员注意力监测。 这是汽车安全召回领域的一个里程碑，表明涉及安全的缺陷可以通过远程软件更新解决，车主无需前往服务中心。它凸显了特斯拉以软件为先的思路，也可能促使其他车企将 OTA 更新作为召回的常用手段。 第一项召回自 9 月 25 日起生效，涉及 298 万辆进口和国产 Model 3、Model Y、Model S、Model X；OTA 修复加入警示标签，并在碰撞导致断电后降下车窗，以便在紧急车门释放把手难以找到时帮助逃生。第二项召回立即开始，涉及 274 万辆国产 Model 3 和 Model Y，在辅助转向等功能开启时加强驾驶员注意力监测。

**背景**: 许多现代特斯拉车型使用电子车门释放按钮而非传统机械式门把手，并配有隐藏式机械应急拉索；碰撞导致断电后，车内人员可能难以找到或操作释放装置。驾驶员注意力监测系统通过方向盘和踏板行为，以及在较新车型中通过面向座舱的红外摄像头，来识别疲劳或分心迹象。OTA（空中）更新使车企可以像为手机推送更新一样远程向车辆发送新软件，因此不少召回如今无需进店维修即可完成。

## [长江存储科创板 IPO 获受理，拟融资 330 亿元](https://api3.cls.cn/share/article/2461025?os=android&amp;sv=8.8.2&amp;app=cailianpress) ⭐️ 8.0/10

上海证券交易所已受理长江存储科技有限责任公司的科创板 IPO 申请，公司拟融资 330 亿元人民币。据 Counterpoint 数据，2026 年第二季度长江存储按出货容量首次跻身全球 NAND 市场前三名。 这标志着中国半导体存储产业的一个重要里程碑，长江存储已成为全球前三的 NAND 闪存供应商。此次 IPO 可能为其扩充存储制造产能提供资金，进而影响全球 NAND 市场格局。 本次 IPO 的保荐机构为中信证券和中信建投。根据招股书，长江存储 2026 年 1 至 3 月营收为 470.42 亿元，归母净利润为 333.79 亿元。
